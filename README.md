브랜드: 전기관리파트너스 / ELECTRIC PARTNERS  
제작 기준: 2026-09-17  
서비스: 전기안전관리자 상주 위탁 · 직무고시 대행

## 바로 확인

`전기관리파트너스_미리보기.html`을 PC의 Chrome 또는 Edge에서 엽니다. 별도 설치 없이 지역 탭, 서비스 선택, 지역 검색, 3단계 견적문의 흐름을 살펴볼 수 있습니다. 파일 미리보기 앱이 스크립트를 막는 경우 PC 브라우저로 여세요.

미리보기는 검토 편의를 위해 각 화면을 하나의 파일에 담았습니다. 실제 배포용 `dist/`에는 지역·서비스마다 별도 HTML 문서가 있습니다. 미리보기 파일 하나를 검색노출 사이트 대신 배포하지 마세요.

현재는 디자인·동작 검토본입니다. 실제 도메인 연결, 광고 집행, 문의 수집·DB 저장, 문자·이메일 발송은 실행하지 않았습니다. 검토용 입력값은 브라우저 메모리에서만 처리하며 저장소·쿠키·외부 분석 도구에 보관하지 않습니다. 실제 개인정보가 아닌 테스트 정보로 확인하세요.

## 이번 반영 사항

기존의 두 기둥 심볼과 짙은 녹색·라임·아이보리 디자인을 유지했습니다. 긴 브랜드명을 위한 PC·모바일 로고 배치를 조정했습니다.

상주 위탁과 직무고시 대행을 각각 독립 메뉴·설명 페이지·지역 페이지·견적 흐름으로 분리했습니다. 직무고시만 의뢰하는 고객에게 상주 인원 운영조건을 요구하지 않습니다. 둘 다 문의하는 선택지도 있습니다.

서울·인천·경기·충북·충남 아래의 지역을 가나다순으로 배열했습니다. 메인 지역 목록, 전체 지역 검색, 문의창, 지역 간 이동에서 같은 데이터 배열을 사용합니다. 서울·인천 세부 지역과 기존에 빠졌던 시·군을 추가했습니다.

거래처명·로고·현장사진·수행 사례·후기·가공된 실적 수치는 넣지 않았습니다. 배전반과 점검카드는 직접 작성한 CSS 일러스트이며, 실제 고객 현장이나 점검성적서가 아닙니다.

## 페이지 구성

총 208개 HTML 문서이며, 오류 안내용 404 문서도 포함한 수입니다.

| 종류 | 수 |
|---|---:|
| 권역 대표 페이지: 5개 권역 × 2개 서비스 | 10 |
| 세부 지역 페이지: 93개 지역 × 2개 서비스 | 186 |
| 메인·지역목록·서비스 2개·가이드 4개·운영·개인정보·견적·404 | 12 |
| 합계 | 208 |

세부 지역은 서울 25, 인천 11, 경기 31, 충북 11, 충남 15입니다. 광역시의 구·군, 도의 시·군을 기본 단위로 삼았습니다. 수원·청주 등의 일반구나 읍·면·동까지 각각 확장한 것은 아닙니다. 인천은 공식 행정구역 안내의 2026-07-01 기준을 반영했습니다. 참고자료는 `docs/SOURCES.md`에 있습니다.

예시:

```text
/regions/gyeonggi/siheung/       시흥 상주 위탁
/regions/gyeonggi/siheung/duty/  시흥 직무고시 대행
/regions/seoul/gangnam/         서울 강남구 상주 위탁
/regions/incheon/seohae/duty/   인천 서해구 직무고시 대행
```

실제 구성 전체는 `docs/route-manifest.json`과 `docs/build-report.json`에서 확인합니다. 지역 페이지 수는 실제 검색노출·방문자 수·사업장 수를 뜻하지 않습니다. 지역 안내는 지사 보유나 즉시 인력 배치를 보장하지 않으며 실제 계약 전 수행 가능 여부를 확인해야 합니다.

## 도메인 후보

`electricpartners.com`과 `elecpartners.com`을 설정 후보로만 기록했습니다. 어느 주소도 구매·연결·소유 확인하지 않았습니다. `config/site.json`의 `origin`은 의도적으로 비어 있습니다.

구매 후 대표 도메인 하나를 정해 `origin`에 끝 슬래시 없는 HTTPS 주소로 입력하면 canonical·사이트맵·사이트 구조화 정보가 그 주소로 생성됩니다. 두 주소를 모두 사용할 경우 별도 호스팅 설정에서 보조 도메인을 대표 도메인으로 리디렉션하는 방식을 검토하세요. 현재 파일에는 DNS 변경이나 리디렉션을 실제 적용하지 않았습니다.

## 수정·빌드

외부 Python 패키지 없이 Python 3.12 이상에서 빌드하는 구조입니다. 제작 환경의 Python 3.13에서 확인했습니다.

```sh
python3 scripts/build.py
```

Windows에서 Python 실행명이 다른 경우:

```powershell
py scripts/build.py
```

지역은 `content/regions.json`, 브랜드와 도메인 후보는 `config/site.json`, 페이지 구성·문구는 `scripts/build.py`, 화면 스타일은 `assets/style.css`에서 관리합니다. 빌드하면 지역 목록을 가나다순으로 정리하고 실제 각 HTML 파일과 독립 실행 미리보기를 새로 생성합니다. 수정한 소스가 아니라 `dist/` 파일만 직접 고치면 다음 빌드에 사라집니다.

로컬 배포 구조 확인:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 이것은 PC 내부의 확인용 서버이며 인터넷 배포가 아닙니다.

## 운영 사업자와 개인정보

제공받은 사업자등록증의 상호·대표·등록번호만 운영정보에 반영했습니다. 등록증 원본, 생년월일, 상세 주거주소는 포함하지 않았습니다. 홈페이지 운영은 이은주 사업자, 견적·계약·수행은 ㈜에프앤비종합관리라는 설정안입니다. 실제 관계·등록범위·업무범위는 공개 전 확정해야 합니다. 홈페이지에 쓴 브랜드명은 법적 사업자 상호와 구분합니다.

표시할 연락처·주소와 개인정보처리자·수집항목·보유기간·위탁/제공 관계 등을 확정한 뒤 `content/privacy-approved.html`을 작성합니다. 기본 개인정보 문서는 승인된 법률 문서가 아니라 검토안입니다. 실제 서비스의 국외 처리·이전 등도 확인해야 합니다. 검토하지 않은 항목을 단순히 `verified=true`로 바꾸지 마세요.

## 문의 연결 상태

프론트엔드의 서비스 선택과 입력 검증은 동작합니다. 실제 문의 기능은 `form.enabled=false`로 꺼져 있습니다. Worker·D1·Turnstile·선택 알림 웹훅 코드는 있지만, 실제 계정·자원과 연결하거나 운영환경에서 시험하지 않았습니다.

공개 웹 관리자 화면은 없습니다. 권한 있는 운영자가 문의를 확인할 인증된 관리 도구는 별도 연결이 필요합니다. 문의 전체를 공개 조회하는 API도 만들지 않았습니다. 문자·이메일 수신 기능은 수신 서비스와 연동·테스트해야 합니다. 공개 접수 이후에만 저장 성공 응답을 받아 접수 완료를 표시합니다.

`docs/DEPLOYMENT.md`에는 실제 연결을 맡는 개발자용 설정과 남은 과제를 정리했습니다. 비밀키를 채팅·Git·프론트엔드에 넣지 마세요.

## 검색 공개

지금은 모든 페이지 `noindex`이며, 확인되지 않은 주소를 canonical로 만들지 않습니다. `noindex`는 접근통제가 아니므로 외부 검토용 서버는 별도 비밀번호·Access 등으로 보호하세요.

공개 준비를 마치고 `mode=production`, `origin` 및 실제 운영정보를 확정한 뒤 `seo.approvedPaths`에 검토한 경로를 추가합니다. 승인된 페이지에만 색인 허용·자기참조 canonical·사이트맵이 적용됩니다. 생성된 208페이지를 무조건 한꺼번에 승인할 필요는 없습니다. 내용과 실제 제공 범위를 검토하고 필요한 페이지부터 공개합니다.

검색량 분석 결과나 키워드별 순위는 이 제작물에 없습니다. 지역별 주소가 있다고 검색등록·상위노출·파워링크 1위가 자동으로 이루어지는 것은 아닙니다. 지역별 비슷한 표현을 별도 저가치 페이지로 반복 생성하는 방식도 사용하지 않았습니다.

## 테스트

```sh
node --test tests/worker.test.js
```

24개 서버 단위 테스트가 모의 DB와 모의 Turnstile 응답으로 통과했습니다. 실제 Cloudflare 운영 연동 검증을 뜻하지 않습니다. SQL 마이그레이션은 로컬 SQLite에서 신규 테이블 구성과 문의 삽입을 확인했습니다.

선택 브라우저 검사에는 Playwright·BeautifulSoup4·Chromium이 별도로 필요합니다. 해당 라이브러리나 브라우저는 제작파일에 포함하지 않습니다.

```sh
python3 tests/design_qa.py --chromium /path/to/chromium
```

208개 제목·H1·내부링크와 모든 지역 가나다순, 상주/직무고시/복합 문의의 분기·검증·미전송, 주요 8개 화면의 320/375/390/768/1024/1440px 가로 넘침을 검사했습니다. 브라우저에는 단독 HTML을 직접 렌더링하여 화면 전환을 검증했습니다. 실제 DNS·호스팅·전체 보안감사·모든 브라우저 검증은 아닙니다.
