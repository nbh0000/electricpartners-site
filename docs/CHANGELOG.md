# 디자인 03 변경 내역 (리디자인)

2026-09-17 / 전기관리파트너스

클라이언트 요청(업체 비교·입점 플랫폼이 아닌, 단일 브랜드의 지역별 검색 대응형 영업 홈페이지)에 맞춰 전면 리디자인했습니다. 레퍼런스 사이트의 딥네이비·블루 그라데이션, 큰 흰색 헤드라인, 라운드 카드, 원형 화살표 버튼 스타일을 적용했으며 서체는 Pretendard + Poppins입니다.

메인 첫 화면은 ‘전기안전관리자 상주선임·위탁’을 중심으로 구성하고, 신규 상주선임 / 위탁업체 변경 / 직접고용→위탁 전환 세 가지 상담 경로 카드를 배치했습니다. 직무고시 대행은 별도 서비스 메뉴·섹션·문의 항목으로 유지했습니다.

지역 페이지는 “{지역} 전기안전관리자 상주선임·위탁” 형식의 제목과 지역명이 포함된 설명·본문·FAQ를 갖도록 문구를 다시 썼습니다. 검색 노출을 위한 meta description 을 페이지별로 생성합니다.

“DESIGN PREVIEW”, “ILLUSTRATION / NOT A REPORT”, “EP / 02”, 반복적인 면책 문구 등 영업용 사이트에 어색한 문구를 걷어냈습니다. 지사 소재지가 아니라는 안내는 푸터와 회사 소개에 한 줄로 남겼습니다.

`assets/img/` 에 Gemini 로 생성한 배경 이미지 5장(hero, region, onsite, inspection, about)을 추가했습니다. 실제 고객 현장 사진이 아니며 데스크톱/모바일 두 가지 크기로 제공합니다. 스크롤 등장 애니메이션과 헤더 스크롤 상태를 추가했습니다(prefers-reduced-motion 존중).

도메인을 elecmanagepartners.com 으로 설정했습니다(`config/site.json` 의 origin). 모드는 여전히 preview 이며, 실제 문의 접수는 운영 설정 확인 후 활성화합니다.

# 디자인 02 변경 내역

2026-09-17 / 전기관리파트너스

브랜드와 영문 표기를 전기관리파트너스 / ELECTRIC PARTNERS로 적용했습니다. 기존 심볼·짙은 녹색·라임·아이보리 디자인을 유지하고 긴 이름의 모바일 배치를 조정했습니다.

메인 화면에 상주 위탁과 직무고시 대행의 독립 카드·CTA를 만들고 점검 절차 섹션을 추가했습니다. 직무고시 서비스·비용 가이드·서비스별 지역 페이지를 추가했습니다.

지역 목록을 5권역·93세부 지역으로 확대하고 가나다순으로 통일했습니다. 세부 지역은 두 서비스의 독립 주소를 갖습니다. 전체 지역 검색은 서비스 선택에 따라 해당 페이지를 연결합니다.

견적 양식에 서비스·점검유형·정전 가능조건을 추가했습니다. 직무고시 단독 의뢰 시 상주 운영필드는 비활성화하고, 상주 단독 의뢰 시 직무고시 상세필드는 비활성화합니다. 지역·서비스의 자동 선택을 유지했습니다.

서버의 허용 입력과 SQL 스키마에 새 필드를 반영했습니다. 기존 DB용 순차 마이그레이션 0002를 추가했습니다. 접수번호 접두어를 EP로 변경했습니다. 실제 문의는 여전히 비활성입니다.

가공된 후기·실적·검색량·고객 식별정보는 넣지 않았습니다. 지역 수는 검색 노출 수가 아닙니다.
